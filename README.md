# CloudSec 

CloudSec is an automated Cloud Security Posture Management (CSPM) tool designed to detect common security misconfigurations in cloud environments.

##  Project Goal

The goal of CloudSec is to automatically analyze cloud resources, identify security weaknesses, assign severity levels, and generate a security report.

## Planned Features

- Cloud security configuration scanning
- Network security checks
- Identity and access management checks
- Storage security checks
- Security severity classification
- Security scoring
- Automated security reports
- Terraform infrastructure
- GitHub Actions security pipeline

## Technologies

- Python
- Microsoft Azure
- Terraform
- GitHub Actions
- Linux
- Cloud Security
